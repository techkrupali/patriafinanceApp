# Stitch Designs — drop zone

Client na Stitch project ni files aya nakhvi. Claude aa folder read kari ne
exact aa designs pramane app na screens banavse.

Su nakhvu (koi pan / badhu chale):
- **Code export** — Stitch ma screen par "Code" / export karo → .html file
- **Screenshots** — .png / .jpg (screen na naam sathe hoy to best, e.g. `wallet-child.png`)
- **Design docs** — DESIGN.md / tokens / koi pan notes

Subfolders banavva hoy to banavo (e.g. `wallets/`, `home/`) — badhu scan thase.
